# SI-KASIR Workspace Rules

## Technology Stack
- Framework: React 18+ with Vite
- Database: Firebase Realtime Database (via Firebase JS SDK v10+)
- Styling: Bootstrap 5.3 + FontAwesome 6 + Custom Vanilla CSS / Glassmorphism
- State Management: React Context API (AuthContext)

## Coding Guidelines
- Use React Functional Components with Hooks.
- Keep components modular and reusable under `src/components/` and pages under `src/pages/`.
- Preserve UI/UX modern aesthetic standards (clean cards, smooth micro-interactions, responsive design).
